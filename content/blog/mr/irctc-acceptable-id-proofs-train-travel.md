## TL;DR
भारतीय रेल्वेवर पुष्टी केलेल्या किंवा RAC तिकीटासह प्रवास करताना, तुम्हाला एक वैध ओळख पुरावा बाळगणे आवश्यक आहे. तिकीट परीक्षक (TTE) त्यांच्या मूळ भौतिक स्वरूपात 10 अधिकृत ID पुरावे स्वीकारतात, ज्यामध्ये आधार, मतदार ID, पासपोर्ट, ड्रायव्हिंग लायसन्स, आणि PAN कार्ड समाविष्ट आहेत. डिजिटल ID फक्त अधिकृत DigiLocker किंवा mAadhaar अॅप्समध्ये थेट दाखवल्यास स्वीकारले जातात. तुमच्या ID कार्डची फोटोकॉपी, स्क्रीनशॉट, किंवा फोटो बाळगणे कठोरपणे अमान्य आहे आणि तिकीटाशिवाय प्रवास केल्याबद्दल दंड होऊ शकतो.

## रेल्वे प्रवासासाठी अधिकृत स्वीकारलेले ID पुरावे कोणते आहेत?

**भारतीय रेल्वेवर प्रवास करण्यासाठी, तुम्हाला मूळ स्वरूपात 10 अधिकृत मान्यताप्राप्त ओळख पत्रांपैकी एक बाळगणे आवश्यक आहे. हे स्वीकारलेले ID पुरावे तुमचे आधार कार्ड, मतदार ID, पासपोर्ट, ड्रायव्हिंग लायसन्स, PAN कार्ड, राष्ट्रीयकृत बँक पासबुक, विद्यार्थ्यांचे फोटो ID, सरकारी जारी केलेले फोटो ID कार्ड, फोटोसह क्रेडिट कार्ड, किंवा स्थानिक प्राधिकरणाने जारी केलेले फोटो ID कार्ड समाविष्ट आहेत.**

जर तुम्ही पुष्टी केलेल्या तिकीटासह किंवा RAC (रद्दीकरणाविरुद्ध आरक्षण) सीटसह ट्रेनमध्ये चढत असाल, तर तुम्हाला आरक्षणावर नाव असलेल्या प्रवाशाचे प्रमाणित करणे आवश्यक आहे. TTE हे तपासतो जेणेकरून तिकीट काळ्या बाजारात विक्री आणि ओळख फसवणूक रोखता येईल.

भारतीय रेल्वेने मान्यता दिलेल्या 10 स्वीकारलेले ID पुराव्यांची संपूर्ण, अधिकृत यादी खालीलप्रमाणे आहे:

| # | स्वीकारलेले ID पुरावे | अधिकृत आवश्यकता |
|---|---|---|
| 1 | **आधार कार्ड** | भौतिक कार्ड, e-आधार प्रिंटआउट, किंवा DigiLocker / mAadhaar द्वारे डिजिटल |
| 2 | **मतदार ओळख पत्र** | भारताच्या निवडणूक आयोगाने जारी केलेले मूळ कार्ड |
| 3 | **पासपोर्ट** | वैध मूळ पासपोर्ट (विदेशी पर्यटकांसाठी अत्यंत शिफारस केलेले) |
| 4 | **ड्रायव्हिंग लायसन्स** | प्रादेशिक RTO द्वारे जारी केलेले मूळ लायसन्स |
| 5 | **PAN कार्ड** | आयकर विभागाने जारी केलेले मूळ स्थायी खाते क्रमांक कार्ड |
| 6 | **विद्यार्थी फोटो ID कार्ड** | मान्यता प्राप्त शाळा, महाविद्यालये, किंवा विद्यापीठांनी जारी केलेले |
| 7 | **बँक पासबुक** | फोटोसह लॅमिनेटेड पासबुक, राष्ट्रीयकृत किंवा अनुसूचित बँकांनी जारी केलेले |
| 8 | **क्रेडिट कार्ड** | बँकांनी फोटोसह जारी केलेले लॅमिनेटेड क्रेडिट कार्ड |
| 9 | **स्थानिक प्राधिकरण फोटो ID** | जिल्हा प्रशासन, नगरपालिका संस्था, किंवा पंचायत द्वारे जारी केलेले क्रमांकित फोटो ID कार्ड |
| 10 | **सरकारी ID कार्ड** | केंद्रीय, राज्य, किंवा PSU विभागांनी जारी केलेले फोटो ओळख पत्र |

## भारतीय रेल्वेवर तुमच्या ID कार्डची डिजिटल कॉपी किंवा फोटो वैध आहे का?

**नाही, तिकीट परीक्षक (TTE) द्वारे तुमच्या फोनवरील ओळख पत्रांचे फोटोकॉपी, स्क्रीनशॉट, किंवा यादृच्छिक फोटो वैध ओळख पुराव्याच्या रूपात स्वीकारले जात नाहीत. भारतीय रेल्वे फक्त भौतिक मूळ ID कार्ड किंवा अधिकृत सरकारी प्लॅटफॉर्मवर DigiLocker किंवा अधिकृत mAadhaar मोबाइल अनुप्रयोगाद्वारे सत्यापित डिजिटल दस्तऐवजांना मान्यता देते.**

अनेक प्रवासी त्यांच्या गॅलरी किंवा व्हॉट्सअॅपमध्ये जतन केलेल्या आधार किंवा PAN कार्डाच्या फोटोवर विश्वास ठेवण्याची चूक करतात. तथापि, TTE यांना हे नाकारण्याचे कठोर निर्देश आहेत. स्क्रीनशॉट आणि इमेज फाइल संपादित करणे सोपे आहे, आणि त्यांना स्वीकारणे अनधिकृत तिकीट हस्तांतरणास सुलभ करते.

जर तुम्ही भौतिक मूळ कार्ड सादर करू शकत नसाल, तर तुम्हाला मान्यताप्राप्त अॅप वापरावे लागेल. एक **सध्याचे उपलब्ध तिकीट** म्हणजे एक **पूर्णपणे पुष्टी केलेली सीट** ज्यामध्ये कोच/बर्थ क्रमांक असतात, जे पहिल्या चार्टच्या तयार होण्याच्या वेळी उघडते (सुमारे 8 तास आधी) आणि 30 मिनिटे आधी बंद होते. जर तुम्ही या अंतिम क्षणीच्या तिकिटांपैकी एक मिळवले, तर तुम्ही तुमचे भौतिक ID किंवा तुमचे डिजिटल अॅप लॉग इन केलेले असल्याची खात्री करा, जेणेकरून तुम्ही प्लॅटफॉर्मवर पाऊल ठेवू शकाल.

## तुम्ही TTE ला DigiLocker मध्ये तुमचे आधार कार्ड दाखवू शकता का?

**होय, अधिकृत DigiLocker अॅपमध्ये तुमचे आधार कार्ड, ड्रायव्हिंग लायसन्स, किंवा इतर दस्तऐवज दाखवणे रेल्वे प्रवासासाठी पूर्णपणे वैध आहे. तिकीट परीक्षक (TTE) ला या डिजिटल स्वरूपांना स्वीकारणे कायद्यानुसार आवश्यक आहे, बशर्ते ते अॅपमध्ये थेट उघडले जातात आणि स्क्रीनशॉट किंवा डाउनलोड नसतात.**

DigiLocker हा इलेक्ट्रॉनिक्स आणि माहिती तंत्रज्ञान मंत्रालयाद्वारे चालविला जाणारा सुरक्षित क्लाउड प्लॅटफॉर्म आहे. त्यामध्ये असलेले दस्तऐवज त्यांच्या भौतिक समकक्षांप्रमाणेच कायदेशीर वजन बाळगतात.

रेल्वेवर वापरण्यासाठी:
- TTE च्या समोर DigiLocker अॅप उघडा.
- "जारी केलेले दस्तऐवज" विभागात जा.
- तुमचे आधार कार्ड किंवा ड्रायव्हिंग लायसन्स उघडा.
- TTE ला दस्तऐवज आणि त्याचा अद्वितीय QR कोड पाहण्याची परवानगी द्या.

तुमच्या ईमेलमधून डाउनलोड केलेले PDF फाइल किंवा DigiLocker इंटरफेसचे स्क्रीनशॉट नाकारले जातील. दस्तऐवजाची प्रामाणिकता सिद्ध करण्यासाठी अॅपने थेट दस्तऐवज मिळवणे आवश्यक आहे.

## जर तुम्ही वैध ID पुरावा न घेता ट्रेनमध्ये प्रवास केला तर काय होते?

**जर तुम्हाला वैध, मूळ ID पुरावा न घेता प्रवास करताना पकडले गेले, तर तुम्हाला तिकीट न घेता प्रवास करत असल्याचे मानले जाईल. तिकीट परीक्षक (TTE) तुम्हाला प्रवासासाठी पूर्ण तिकीट दर आणि ₹500 (जन विश्वास अधिनियम, 2026 अंतर्गत सुधारित) दंड आकारेल, आणि तुम्हाला ट्रेन सोडण्यास सांगितले जाऊ शकते.**

तुमच्याकडे तुमच्या नावावर एक पूर्णपणे वैध पुष्टी केलेले तिकीट बुकिंग असले तरी, जुळणारे ID सादर न केल्यास ते अमान्य होते. रेल्वे प्रणाली मानते की तुम्ही दुसऱ्या व्यक्तीच्या तिकिटावर प्रवास करत आहात.

जर तुम्ही गट बुकिंगवर असाल, तर तिकिटावर सूचीबद्ध असलेल्या किमान एका प्रवाशाने वैध ID सादर करणे आवश्यक आहे. जर गटातील कोणालाही ID नसेल, तर संपूर्ण गट तिकीटविहीन म्हणून चिन्हांकित केला जातो. TTE प्रत्येक व्यक्तीसाठी तिकीट दर आणि दंड आकारेल. राजधानी किंवा शताब्दी सारख्या प्रीमियम ट्रेन्समध्ये, दंड उच्चतम वर्गाच्या तिकिटाच्या दराशी जुळतो, जो खूप महाग असू शकतो.

## WL आणि RAC तिकिटांसाठी ID सत्यापन कसे कार्य करते?

**RAC आणि वेटलिस्टेड तिकिटांसाठी, तिकिटावर बुक केलेल्या किमान एका प्रवाशाने सत्यापनादरम्यान वैध ID पुरावा दाखवावा लागतो. तथापि, जर तुमचे e-तिकिट चार्ट तयार झाल्यानंतर वेटलिस्टवर राहिले, तर ते स्वयंचलितपणे रद्द होते, आणि तुम्ही त्याचा वापर करून ट्रेनमध्ये चढू शकत नाही.**

प्रथम, तुम्हाला वेटलिस्ट नियम समजून घ्यावे लागतील. **WL चा पूर्ण अर्थ आहे वेटिंग लिस्ट**. बुकिंग करताना, तिकिटे स्पष्ट रांगेत प्रगती करतात: **WL (वेटिंग लिस्ट) → RAC (रद्दीकरणाविरुद्ध आरक्षण) → पुष्टी केलेले**.

जर तुम्हाला भौतिक काउंटर तिकीट असेल जे अजूनही वेटलिस्टवर आहे, तर तुम्हाला सामान्य कोचमध्ये प्रवास करण्याची परवानगी आहे, परंतु तुम्हाला वैध ID बाळगणे आवश्यक आहे. ऑनलाइन e-तिकिटांसाठी, जर तुमची स्थिती RAC किंवा पुष्टी केलेली नसती, तर ते स्वयंचलितपणे रद्द होते आणि तुमच्या पेमेंट पद्धतीवर परत केले जाते.

जर तुम्ही वेटलिस्टवर अडकले असाल, तर तुमच्या पुष्टीकरणाच्या शक्यता [LastBerth](/) वर तपासा. जर तुमच्या PNR स्थितीमध्ये कमी संभाव्यता दर्शविली गेली, तर वैध बुकिंगशिवाय प्रवास करण्याचा धोका घेऊ नका. तुम्ही [LastBerth](/) वापरून पर्याय शोधू शकता किंवा [Finding Smart Seats](/) वैशिष्ट्याचा वापर करून एकाच थेट सीट उपलब्ध नसलेल्या अनेक कोच/सेगमेंटमध्ये सीट बुकिंग तोडू शकता. तुम्ही [Seat Status Coach Journey Lookup](/seat-status) वापरून खुले बर्थ ओळखू शकता आणि सुरक्षित प्रवास सुनिश्चित करू शकता.

## IRCTC स्वीकारलेले ID पुरावे रेल्वे प्रवासासाठी (FAQ)

### भारतीय रेल्वेमध्ये 10 स्वीकारलेले ID पुरावे कोणते आहेत?
10 स्वीकारलेले ID पुरावे आहेत आधार कार्ड, मतदार ID, पासपोर्ट, ड्रायव्हिंग लायसन्स, PAN कार्ड, विद्यार्थी ID, बँक पासबुक, फोटो क्रेडिट कार्ड, सरकारी ID, आणि स्थानिक प्राधिकरणाचे फोटो ID.

### माझ्या फोनवरील ID कार्डाचा फोटो वैध आहे का?
नाही, फोटो, स्क्रीनशॉट, किंवा ID च्या झेरॉक्स कॉपी वैध नाहीत. फक्त मूळ भौतिक ID किंवा DigiLocker/mAadhaar मध्ये सत्यापित केलेले स्वीकारले जातात.

### मी माझ्या फोनवरील PAN कार्डाची डिजिटल कॉपी वापरू शकतो का?
फक्त जर तुम्ही ते DigiLocker द्वारे प्रवेश करता. नियमित PDF डाउनलोड किंवा PAN कार्डाचे इमेज TTE द्वारे स्वीकारले जात नाहीत.

### वैध ID न घेऊन प्रवास केल्यास दंड काय आहे?
तुम्हाला तिकीट न घेता प्रवास करत असल्याचे मानले जाईल, म्हणजे तुम्हाला वास्तविक तिकीट दर आणि ₹500 (जन विश्वास अधिनियम, 2026 अंतर्गत सुधारित) चा किमान दंड द्यावा लागेल.

### गट तिकिटावर सर्व प्रवाशांनी ID दाखवावी लागते का?
नाही, फक्त तिकिटावर नाव असलेल्या एका प्रवाशाने सत्यापनादरम्यान वैध ID पुरावा सादर करणे आवश्यक आहे.

### TTE द्वारे m-Aadhaar वैध ID पुरावा म्हणून स्वीकारला जातो का?
होय, अधिकृत UIDAI मोबाइल अॅपवर प्रदर्शित केलेले डिजिटल m-Aadhaar भारतीय रेल्वे द्वारे वैध ओळख पुराव्याच्या रूपात पूर्णपणे मान्य आहे.

### महाविद्यालयीन विद्यार्थ्यांचे ID कार्ड सामान्य रेल्वे प्रवासासाठी वापरले जाऊ शकते का?
नाही, विद्यार्थी ID कार्ड फक्त विद्यार्थी सवलतीच्या तिकिटांसाठी स्वीकारले जातात. मानक प्रवासासाठी आधार, PAN, मतदार ID, किंवा पासपोर्ट सारख्या सरकारी जारी केलेल्या फोटो ओळख पुराव्याची आवश्यकता आहे.

### जर कुटुंब तिकिटावर फक्त एका प्रवाशाकडे ID असेल तर काय होते?
भारतीय रेल्वेच्या व्यावसायिक नियमांनुसार, बहु-प्रवासी e-तिकिटावर सूचीबद्ध असलेल्या किमान एका प्रवाशाने मूळ वैध फोटो ID बाळगणे आवश्यक आहे जेणेकरून संपूर्ण गटाच्या प्रवासाची वैधता सिद्ध होईल.
