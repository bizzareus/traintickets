## TL;DR
भारतीय रेल्वेवर निश्चित किंवा RAC तिकीट घेऊन प्रवास करताना, तुम्हाला एक वैध ओळख पुरावा सोबत ठेवावा लागतो. तिकीट परीक्षक (TTE) त्यांच्या मूळ भौतिक स्वरूपात 10 अधिकृत ID पुरावे स्वीकारतात, ज्यात आधार, मतदार ID, पासपोर्ट, ड्रायविंग लायसन्स, आणि PAN कार्ड समाविष्ट आहेत. डिजिटल ID फक्त अधिकृत DigiLocker किंवा mAadhaar अॅप्समध्ये थेट दाखविल्यास स्वीकारली जातात. तुमच्या ID कार्डची फोटोकॉपी, स्क्रीनशॉट, किंवा फोटो घेऊन जाणे कठोरपणे अमान्य आहे आणि तिकीट न घेता प्रवास केल्याबद्दल तुम्हाला दंडित केले जाऊ शकते.

## रेल्वे प्रवासासाठी अधिकृत स्वीकार्य ID पुरावे कोणते आहेत?

**भारतीय रेल्वेवर प्रवास करण्यासाठी, तुम्हाला मूळ स्वरूपात 10 अधिकृत मान्यताप्राप्त ओळख कार्डांपैकी एक सोबत ठेवावे लागते. या स्वीकार्य ID पुराव्यात तुमचा आधार कार्ड, मतदार ID, पासपोर्ट, ड्रायविंग लायसन्स, PAN कार्ड, राष्ट्रीयीकृत बँक पासबुक, विद्यार्थ्यांचे फोटो ID, सरकारी जारी केलेले फोटो ID कार्ड, फोटोसह क्रेडिट कार्ड, किंवा स्थानिक प्राधिकरणाने जारी केलेले फोटो ID कार्ड समाविष्ट आहेत.**

जर तुम्ही निश्चित तिकीट किंवा RAC (रद्दीकरणाविरुद्ध आरक्षण) आसनासह ट्रेनमध्ये चढत असाल, तर तुम्हाला आरक्षणावर नाव असलेल्या प्रवाशाचे प्रमाणित करणे आवश्यक आहे. TTE हे चेक करतो जेणेकरून तिकीट काळा बाजार आणि ओळख फसवणूक टाळता येईल.

भारतीय रेल्वेने मान्य केलेल्या 10 स्वीकार्य ID पुराव्यांची संपूर्ण, अधिकृत यादी खालीलप्रमाणे आहे:

| # | स्वीकार्य ID पुरावा | अधिकृत आवश्यकता |
|---|---|---|
| 1 | **आधार कार्ड** | भौतिक कार्ड, e-आधार प्रिंटआउट, किंवा DigiLocker / mAadhaar द्वारे डिजिटल |
| 2 | **मतदार ओळख पत्र** | भारताच्या निवडणूक आयोगाने जारी केलेले मूळ कार्ड |
| 3 | **पासपोर्ट** | वैध मूळ पासपोर्ट (परदेशी पर्यटकांसाठी अत्यंत शिफारस केलेले) |
| 4 | **ड्रायविंग लायसन्स** | प्रादेशिक RTOs द्वारे जारी केलेले मूळ लायसन्स |
| 5 | **PAN कार्ड** | आयकर विभागाने जारी केलेले मूळ स्थायी खाते क्रमांक कार्ड |
| 6 | **विद्यार्थी फोटो ID कार्ड** | मान्यताप्राप्त शाळा, महाविद्यालये, किंवा विद्यापीठे द्वारे जारी केलेले |
| 7 | **बँक पासबुक** | फोटोसह लॅमिनेटेड पासबुक, राष्ट्रीयीकृत किंवा अनुसूचित बँकांनी जारी केलेले |
| 8 | **क्रेडिट कार्ड** | कार्डधारकाच्या फोटोसह बँकांनी जारी केलेले लॅमिनेटेड क्रेडिट कार्ड |
| 9 | **स्थानिक प्राधिकरण फोटो ID** | जिल्हा प्रशासन, नगरपालिका संस्था, किंवा पंचायत द्वारे जारी केलेले क्रमांकित फोटो ID कार्ड |
| 10 | **सरकारी ID कार्ड** | केंद्रीय, राज्य, किंवा PSU विभागांनी जारी केलेले फोटो ओळख पत्र |

## भारतीय रेल्वेवर तुमच्या ID कार्डची डिजिटल कॉपी किंवा फोटो वैध आहे का?

**नाही, तिकीट परीक्षक (TTEs) द्वारे ओळख पुराव्याच्या रूपात तुमच्या फोनवरील फोटोकॉपी, स्क्रीनशॉट, किंवा यादृच्छिक फोटो स्वीकारले जात नाहीत. भारतीय रेल्वे फक्त भौतिक मूळ ID कार्ड किंवा अधिकृत सरकारी प्लॅटफॉर्मवर जसे DigiLocker किंवा अधिकृत mAadhaar मोबाइल अॅपद्वारे सत्यापित केलेले डिजिटल दस्तऐवज मान्य करते.**

अनेक प्रवासी त्यांच्या गॅलरी किंवा WhatsApp मध्ये जतन केलेल्या आधार किंवा PAN कार्डाच्या फोटोवर विश्वास ठेवण्याची चूक करतात. तथापि, TTEs यांना हे नाकारण्याचे कठोर निर्देश आहेत. स्क्रीनशॉट आणि इमेज फाइल संपादित करणे सोपे आहे, आणि त्यांना स्वीकारल्यास अधिकृत तिकीट हस्तांतरण करणे सोपे होते.

जर तुम्ही भौतिक मूळ कार्ड सादर करू शकत नसाल, तर तुम्हाला मान्यताप्राप्त अॅप वापरावे लागेल. एक **सध्याचे उपलब्ध तिकीट** म्हणजे एक **पूर्णपणे निश्चित आसन** ज्यामध्ये कोच/बर्थ क्रमांक असतात जे पहिल्या चार्टच्या तयार होण्याच्या वेळी उघडतात (सुमारे 8 तास आधी) आणि 30 मिनिटे आधी बंद होतात. जर तुम्ही या अंतिम क्षणीच्या तिकिटांपैकी एक मिळवले, तर तुम्ही तुमचे भौतिक ID किंवा तुमची डिजिटल अॅप लॉग इन केलेली असणे सुनिश्चित करा, जेणेकरून तुम्ही प्लॅटफॉर्मवर पाऊल ठेवू शकाल.

## तुम्ही TTE ला DigiLocker मध्ये तुमचा आधार कार्ड दाखवू शकता का?

**होय, अधिकृत DigiLocker अॅपमध्ये तुमचा आधार कार्ड, ड्रायविंग लायसन्स, किंवा इतर दस्तऐवज दाखवणे ट्रेन प्रवासासाठी पूर्णपणे वैध आहे. तिकीट परीक्षक (TTE) या डिजिटल स्वरूपांना स्वीकारण्यास कायदेशीरपणे बांधील आहे, असे मानले जाते, बशर्ते ते अॅपमध्ये थेट उघडले जातात आणि स्क्रीनशॉट किंवा डाउनलोड नाहीत.**

DigiLocker हा इलेक्ट्रॉनिक्स आणि माहिती तंत्रज्ञान मंत्रालयाद्वारे चालवला जाणारा सुरक्षित क्लाउड प्लॅटफॉर्म आहे. त्यामध्ये असलेले दस्तऐवज त्यांच्या भौतिक समकक्षांप्रमाणेच कायदेशीर वजन ठेवतात.

ट्रेनमध्ये याचा वापर करण्यासाठी:
- TTE च्या समोर DigiLocker अॅप उघडा.
- "जारी केलेले दस्तऐवज" विभागात जा.
- तुमचा आधार कार्ड किंवा ड्रायविंग लायसन्स उघडा.
- TTE ला दस्तऐवज आणि त्याचा अद्वितीय QR कोड पाहण्याची परवानगी द्या.

तुमच्या ई-मेलमधून डाउनलोड केलेले PDF फाइल किंवा DigiLocker इंटरफेसचे स्क्रीनशॉट नाकारले जातील. दस्तऐवजाची प्रामाणिकता सिद्ध करण्यासाठी अॅपने थेट दस्तऐवज आणले पाहिजे.

## वैध ID पुरावा न घेता ट्रेनमध्ये प्रवास केल्यास काय होते?

**जर तुम्हाला वैध, मूळ ID पुरावा न घेता प्रवास करताना पकडले गेले, तर तुम्हाला तिकीट न घेता प्रवास करत असल्यासारखे मानले जाईल. तिकीट परीक्षक (TTE) तुमच्यावर प्रवासासाठी पूर्ण तिकीट भाडे आणि ₹500 (जन विश्वास कायदा, 2026 अंतर्गत सुधारित) दंड आकारेल, आणि तुम्हाला ट्रेन सोडण्यास सांगितले जाऊ शकते.**

तुमच्याकडे तुमच्या नावावर एक पूर्णपणे वैध निश्चित तिकीट बुकिंग असले तरी, जुळणारा ID सादर न केल्यास ते अमान्य होते. रेल्वे प्रणाली मानते की तुम्ही दुसऱ्या व्यक्तीच्या तिकिटावर प्रवास करत आहात.

जर तुम्ही गट बुकिंगवर असाल, तर तिकिटावर सूचीबद्ध असलेल्या किमान एका प्रवाशाने वैध ID सादर करणे आवश्यक आहे. जर गटातील कोणालाही ID नसेल, तर संपूर्ण गट तिकीटविहीन म्हणून चिन्हांकित केला जातो. TTE प्रत्येक व्यक्तीसाठी भाडे आणि दंड आकारेल. राजधानी किंवा शताब्दी सारख्या प्रीमियम ट्रेन्समध्ये, दंड उच्चतम वर्गाच्या भाड्याशी जुळतो, जो खूप महाग असू शकतो.

## WL आणि RAC तिकिटांसाठी ID पडताळणी कशी कार्य करते?

**RAC आणि वेटलिस्टेड तिकिटांसाठी, तिकिटावर बुक केलेल्या किमान एका प्रवाशाने पडताळणी दरम्यान वैध ID पुरावा दाखवावा लागतो. तथापि, जर तुमचे e-तिकिट चार्ट तयार झाल्यानंतर वेटलिस्टमध्ये राहिले, तर ते स्वयंचलितपणे रद्द होते, आणि तुम्ही त्यावर ट्रेनमध्ये चढू शकत नाही.**

सर्वप्रथम, तुम्हाला वेटलिस्ट नियम समजून घ्यावे लागतील. **WL चा पूर्ण अर्थ वेटिंग लिस्ट आहे**. बुकिंग करताना, तिकिटे स्पष्ट रांगेत प्रगती करतात: **WL (वेटिंग लिस्ट) → RAC (रद्दीकरणाविरुद्ध आरक्षण) → निश्चित**.

जर तुम्हाला भौतिक काउंटर तिकीट असेल जे अजूनही वेटलिस्टमध्ये आहे, तर तुम्हाला सामान्य कोचमध्ये प्रवास करण्याची परवानगी आहे, परंतु तुम्हाला वैध ID सोबत ठेवावी लागेल. ऑनलाइन e-तिकिटांसाठी, जर तुमचा स्थिती RAC किंवा निश्चितपर्यंत पोहोचत नसेल, तर ते स्वयंचलितपणे रद्द केले जाते आणि तुमच्या भांडवली पद्धतीत परत केले जाते.

जर तुम्ही वेटलिस्टमध्ये अडकले असाल, तर तुमच्या पुष्टीकरणाच्या संधी तपासा [LastBerth](/). जर तुमच्या PNR स्थितीमध्ये कमी संभाव्यता दर्शविली गेली, तर वैध बुकिंग न करता प्रवास करण्याचा धोका घेऊ नका. तुम्ही [LastBerth](/) वापरून पर्याय शोधू शकता किंवा [Finding Smart Seats](/) वैशिष्ट्य वापरून एकाच थेट आसन उपलब्ध नसलेल्या अनेक कोच/सेगमेंटमध्ये आसन बुकिंग तोडू शकता. तुम्ही [Seat Status Coach Journey Lookup](/seat-status) वापरून खुल्या बर्थची ओळख करून सुरक्षित प्रवास सुनिश्चित करू शकता.

## IRCTC रेल्वे प्रवासासाठी स्वीकार्य ID पुरावे (FAQ)

### भारतीय रेल्वेमध्ये 10 स्वीकार्य ID पुरावे कोणते आहेत?
10 स्वीकार्य ID पुरावे म्हणजे आधार कार्ड, मतदार ID, पासपोर्ट, ड्रायविंग लायसन्स, PAN कार्ड, विद्यार्थी ID, बँक पासबुक, फोटो क्रेडिट कार्ड, सरकारी ID, आणि स्थानिक प्राधिकरणाचे फोटो ID.

### माझ्या फोनवरील ID कार्डाचा फोटो वैध आहे का?
नाही, फोटो, स्क्रीनशॉट, किंवा ID ची झेरॉक्स कॉपी वैध नाही. फक्त मूळ भौतिक IDs किंवा DigiLocker/mAadhaar मध्ये सत्यापित केलेले स्वीकारले जातात.

### मी माझ्या फोनवर PAN कार्डाची डिजिटल कॉपी वापरू शकतो का?
फक्त तुम्ही DigiLocker द्वारे प्रवेश केल्यास. नियमित PDF डाउनलोड किंवा PAN कार्डाचे इमेज TTE द्वारे स्वीकारले जात नाहीत.

### वैध ID न घेऊन प्रवास केल्यास दंड काय आहे?
तुम्हाला तिकीट न घेता प्रवास करत असल्यासारखे मानले जाईल, म्हणजे तुम्हाला वास्तविक तिकीट भाडे आणि किमान ₹500 (जन विश्वास कायदा, 2026 अंतर्गत सुधारित) दंड द्यावा लागेल.

### गट तिकिटावर सर्व प्रवाशांनी ID दाखवावी लागते का?
नाही, तिकिटावर नाव असलेल्या एकाच प्रवाशाने पडताळणी दरम्यान वैध ID पुरावा सादर करणे आवश्यक आहे.
